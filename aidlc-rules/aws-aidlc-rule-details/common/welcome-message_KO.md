# AI-DLC (AI 기반 개발 생명주기)에 오신 것을 환영합니다!

귀하의 특정 요구에 맞게 지능적으로 조정되는 적응형 소프트웨어 개발 워크플로우를 안내해 드리겠습니다.

## AI-DLC란 무엇인가요?

AI-DLC는 프로젝트의 요구에 맞게 적응하는 구조화되면서도 유연한 소프트웨어 개발 프로세스입니다. 다음과 같은 경험 많은 소프트웨어 아키텍트가 있다고 생각하세요:
- **요구사항을 분석**하고 필요할 때 명확화 질문을 합니다
- **복잡성과 리스크에 따라 최적의 접근 방식을 계획**합니다
- **단순한 변경에는 불필요한 단계를 건너뛰고** 복잡한 프로젝트에는 포괄적인 처리를 제공합니다
- **모든 것을 문서화**하여 결정과 근거에 대한 완전한 기록을 제공합니다
- **명확한 체크포인트와 승인 게이트로 각 단계를 안내**합니다

### 단계 상세:

**INCEPTION 단계** - *계획 및 애플리케이션 설계*
- **목적**: 무엇을 만들고 왜 만드는지 결정
- **활동**: 요구사항 이해, 기존 코드 분석 (있는 경우), 접근 방식 계획
- **출력물**: 명확한 요구사항, 실행 계획, 병렬 개발을 위한 작업 단위 수 결정
- **귀하의 역할**: 질문에 답변, 계획 검토, 방향 승인

**CONSTRUCTION 단계** - *상세 설계, 구현 및 테스트*
- **목적**: 어떻게 만들지 결정
- **활동**: 상세 설계 (필요시), 코드 생성, 포괄적 테스트
- **출력물**: 작동하는 코드, 테스트, 빌드 지침
- **귀하의 역할**: 설계 검토, 구현 계획 승인, 결과 검증

**OPERATIONS 단계** - *배포 및 모니터링 (향후)*
- **목적**: 어떻게 배포하고 실행할지
- **상태**: 향후 배포 및 모니터링 워크플로우를 위한 플레이스홀더
- **현재 상태**: 빌드 및 테스트 활동은 CONSTRUCTION 단계에서 처리

## 핵심 원칙:

- **완전 적응형**: 각 스테이지는 귀하의 요구에 따라 독립적으로 평가됩니다
- **효율적**: 단순한 변경은 필수 스테이지만 실행합니다
- **포괄적**: 복잡한 변경은 모든 안전장치와 함께 전체 처리를 받습니다
- **투명함**: 작업 시작 전 실행 계획을 보고 승인합니다
- **문서화됨**: 모든 결정과 변경에 대한 완전한 감사 추적
- **사용자 제어**: 스테이지 포함 또는 제외를 요청할 수 있습니다

## 다음 단계:

1. **워크스페이스를 분석**하여 새 프로젝트인지 기존 프로젝트인지 이해합니다
2. **요구사항을 수집**하고 필요하면 명확화 질문을 합니다
3. **실행 계획을 생성**하여 어떤 스테이지를 실행할 것인지와 그 이유를 보여줍니다
4. **계획을 검토하고 승인**합니다 (또는 변경 요청)
5. **각 주요 스테이지에서 체크포인트와 함께 계획을 실행**합니다
6. **완전한 문서와 테스트가 포함된 작동하는 코드**를 받습니다

AI-DLC 프로세스는 다음에 적응합니다:
- 귀하의 의도 명확성과 복잡성
- 기존 코드베이스 상태
- 변경의 범위와 영향
- 리스크 및 품질 요구사항
