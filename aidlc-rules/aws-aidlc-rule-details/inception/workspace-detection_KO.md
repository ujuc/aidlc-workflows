# 워크스페이스 감지

**목적**: 워크스페이스 상태 파악 및 기존 AI-DLC 프로젝트 확인

## 단계 1: 기존 AI-DLC 프로젝트 확인

`aidlc-docs/aidlc-state.md`가 존재하는지 확인:
- **존재하는 경우**: 마지막 단계에서 재개 (이전 단계에서 컨텍스트 로드)
- **존재하지 않는 경우**: 새 프로젝트 평가로 계속

## 단계 2: 워크스페이스에서 기존 코드 스캔

**워크스페이스에 기존 코드가 있는지 확인:**
- 소스 코드 파일 스캔 (.java, .py, .js, .ts 등)
- 빌드 파일 확인 (pom.xml, package.json, build.gradle 등)
- 프로젝트 구조 지표 검색

**결과 기록:**
```markdown
## 워크스페이스 상태
- **기존 코드**: [예/아니오]
- **프로그래밍 언어**: [발견된 경우 목록]
- **빌드 시스템**: [발견된 경우 Maven/Gradle/npm 등]
- **프로젝트 구조**: [모놀리스/마이크로서비스/라이브러리/빈 상태]
```

## 단계 3: 다음 단계 결정

**워크스페이스가 비어 있는 경우 (기존 코드 없음)**:
- 플래그 설정: `brownfield = false`
- 다음 단계: 요구사항 분석

**워크스페이스에 기존 코드가 있는 경우**:
- 플래그 설정: `brownfield = true`
- `aidlc-docs/inception/reverse-engineering/`에서 기존 리버스 엔지니어링 산출물 확인
- **리버스 엔지니어링 산출물이 존재하는 경우**: 로드하고 요구사항 분석으로 건너뛰기
- **리버스 엔지니어링 산출물이 없는 경우**: 다음 단계는 리버스 엔지니어링

## 단계 4: 초기 상태 파일 생성

`aidlc-docs/aidlc-state.md` 생성:

```markdown
# AI-DLC 상태 추적

## 프로젝트 정보
- **프로젝트 유형**: [그린필드/브라운필드]
- **시작 날짜**: [ISO 타임스탬프]
- **현재 스테이지**: INCEPTION - 워크스페이스 감지

## 워크스페이스 상태
- **기존 코드**: [예/아니오]
- **리버스 엔지니어링 필요**: [예/아니오]

## 스테이지 진행 상황
[워크플로우가 진행됨에 따라 채워짐]
```

## 단계 5: 완료 메시지 제시

**브라운필드 프로젝트의 경우:**
```markdown
# 🔍 워크스페이스 감지 완료

워크스페이스 분석 결과:
- **프로젝트 유형**: 브라운필드 프로젝트
- [AI가 생성한 워크스페이스 결과 요약 (글머리 기호 형식)]
- **다음 단계**: **리버스 엔지니어링**으로 진행하여 기존 코드베이스 분석...
```

**그린필드 프로젝트의 경우:**
```markdown
# 🔍 워크스페이스 감지 완료

워크스페이스 분석 결과:
- **프로젝트 유형**: 그린필드 프로젝트
- **다음 단계**: **요구사항 분석**으로 진행...
```

## 단계 6: 자동 진행

- **사용자 승인 불필요** - 이것은 정보 제공 목적만
- 다음 단계로 자동 진행:
  - **브라운필드**: 리버스 엔지니어링 (기존 산출물이 없는 경우) 또는 요구사항 분석 (산출물이 있는 경우)
  - **그린필드**: 요구사항 분석
