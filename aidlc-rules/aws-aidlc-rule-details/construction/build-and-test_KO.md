# 빌드 및 테스트

**목적**: 모든 유닛을 빌드하고 포괄적인 테스트 전략 실행

## 전제 조건
- 모든 유닛에 대한 코드 생성이 완료되어야 함
- 모든 코드 산출물이 생성되어야 함
- 프로젝트가 빌드 및 테스트 준비가 되어 있어야 함

---

## 단계 1: 테스트 요구사항 분석

프로젝트를 분석하여 적절한 테스트 전략 결정:
- **단위 테스트**: 코드 생성 중 유닛별로 이미 생성됨
- **통합 테스트**: 유닛/서비스 간 상호작용 테스트
- **성능 테스트**: 부하, 스트레스 및 확장성 테스트
- **엔드투엔드 테스트**: 완전한 사용자 워크플로우
- **계약 테스트**: 서비스 간 API 계약 검증
- **보안 테스트**: 취약점 스캐닝, 침투 테스트
