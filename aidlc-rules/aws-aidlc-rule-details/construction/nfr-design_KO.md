# NFR 설계

## 전제 조건
- 해당 유닛에 대한 NFR 요구사항이 완료되어야 함
- NFR 요구사항 산출물이 사용 가능해야 함
- 실행 계획이 NFR 설계 스테이지를 실행해야 함을 표시해야 함

## 개요
패턴과 논리적 컴포넌트를 사용하여 NFR 요구사항을 유닛 설계에 통합합니다.

## 실행 단계

### 단계 1: NFR 요구사항 분석
- `aidlc-docs/construction/{unit-name}/nfr-requirements/`에서 NFR 요구사항 읽기
- 확장성, 성능, 가용성, 보안 요구 이해

### 단계 2: NFR 설계 계획 작성
- NFR 설계를 위한 체크박스 []가 포함된 계획 생성
- 설계 패턴 및 논리적 컴포넌트에 집중
- 각 단계에 체크박스 [] 포함

### 단계 3: 컨텍스트에 적절한 질문 생성
**지시어**: NFR 요구사항을 분석하여 이 특정 유닛의 NFR 설계에 관련된 질문만 생성합니다. 아래 카테고리를 영감으로 사용하고 필수 체크리스트로 사용하지 마세요. 해당되지 않으면 전체 카테고리를 건너뛰세요.

- [Answer]: 태그 형식을 사용하여 질문 포함
- 이 유닛에 특정한 모호함과 누락된 정보에 집중
- 패턴 및 컴포넌트 결정에 사용자 입력이 필요한 경우에만 질문 생성

**예시 질문 카테고리** (필요에 따라 조정):
- **복원력 패턴** - 내결함성 접근 방식에 명확화가 필요한 경우에만
- **확장성 패턴** - 확장 메커니즘이 불명확한 경우에만
- **성능 패턴** - 성능 최적화 전략이 모호한 경우에만
- **보안 패턴** - 보안 구현 접근 방식에 입력이 필요한 경우에만
- **논리적 컴포넌트** - 인프라 컴포넌트 (큐, 캐시 등)에 명확화가 필요한 경우에만

### 단계 4: 계획 저장
- `aidlc-docs/construction/plans/{unit-name}-nfr-design-plan.md`로 저장
- 사용자 입력을 위한 모든 [Answer]: 태그 포함

### 단계 5: 답변 수집 및 분석
- 사용자가 모든 [Answer]: 태그를 완료할 때까지 대기
- 모호하거나 불명확한 응답 검토
- 필요시 후속 질문 추가

### 단계 6: NFR 설계 산출물 생성
- `aidlc-docs/construction/{unit-name}/nfr-design/nfr-design-patterns.md` 생성
- `aidlc-docs/construction/{unit-name}/nfr-design/logical-components.md` 생성

### 단계 7: 완료 메시지 제시
- 다음 구조로 완료 메시지 제시:
     1. **완료 알림** (필수): 항상 이것으로 시작:

```markdown
# NFR 설계 완료 - [unit-name]
```

     2. **AI 요약** (선택): NFR 설계의 구조화된 글머리 기호 요약 제공
        - 형식: "NFR 설계가 [설명]을 통합했습니다:"
        - 구현된 주요 설계 패턴 나열 (글머리 기호)
        - 논리적 컴포넌트 및 인프라 요소 나열
        - 적용된 복원력, 확장성 및 성능 패턴 언급
        - 워크플로우 지침을 포함하지 마세요 ("검토해 주세요", "알려주세요", "다음 단계로 진행", "진행하기 전에")
        - 사실적이고 내용 중심으로 유지
     3. **형식화된 워크플로우 메시지** (필수): 항상 이 정확한 형식으로 끝:

```markdown
> **검토 필요:**
> NFR 설계를 검토해 주세요: `aidlc-docs/construction/[unit-name]/nfr-design/`



> **다음 단계**
>
> **다음 중 선택할 수 있습니다:**
>
> **변경 요청** - 검토를 기반으로 NFR 설계 수정 요청
> **다음 스테이지로 계속** - NFR 설계 승인 및 **[다음 스테이지 이름]**으로 진행

---
```

### 단계 8: 명시적 승인 대기
- 사용자가 NFR 설계를 명시적으로 승인할 때까지 진행하지 않음
- 승인은 명확하고 모호하지 않아야 함
- 사용자가 변경을 요청하면 설계를 업데이트하고 승인 프로세스 반복

### 단계 9: 승인 기록 및 진행 상황 업데이트
- 타임스탬프와 함께 audit.md에 승인 기록
- 타임스탬프와 함께 사용자의 승인 응답 기록
- aidlc-state.md에서 NFR 설계 스테이지 완료 표시
